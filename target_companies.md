## How to find a link like this for another company

1. Go to that company's careers/jobs page directly.
2. Search or filter by "Costa Rica" (or "Remote") using whatever location
   field they offer.
3. Copy the URL from your browser's address bar once results show - most
   career sites put filters directly into the URL, so that link reloads
   the same filtered results next time.
4. Add it to this file with a short label.

If a company's site doesn't put filters in the URL (some single-page apps
hide it), there usually isn't a clean workaround - checking manually stays
the most reliable option for that one.
